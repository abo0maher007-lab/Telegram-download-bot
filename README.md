# Telegram Downloader Bot 🤖

بوت تلغرام لتحميل الفيديوهات والصوتيات من منصات متعددة

## ✨ المميزات

- 🎥 دعم YouTube, Facebook, Instagram, TikTok, Twitter, Reddit, Vimeo
- 📊 اختيار جودة متعددة (144p - 1080p)
- 🎵 تحميل الصوت فقط بصيغة MP3
- 📈 شريط تقدم مباشر
- 🚀 سرعة تحميل عالية
- 💾 دعم ملفات حتى 2GB
- 🔄 تحديثات مباشرة
